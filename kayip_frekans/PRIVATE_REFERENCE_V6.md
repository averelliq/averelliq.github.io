# KAYIP FREKANS_ — özel ses referansı (V6)

GitHub deposu **herkese açıktır**. Orijinal 44,49 saniyelik MP3'ü, WAV'ı veya Base64 içeriğini normal bir GitHub dosyasına/issue'ya/commit'e koymayın. Hazırlanmış kişisel ZIP paketindeki `KF_REF_OPUS_B64_1.txt`, `_2.txt`, `_3.txt` dosyaları yalnızca ilgili üç **Settings → Secrets and variables → Actions → New repository secret** değeridir. İlgili secret adları sırasıyla `KF_REF_OPUS_B64_1`, `KF_REF_OPUS_B64_2`, `KF_REF_OPUS_B64_3` olmalıdır. Üçünün de değeri girilmelidir; kod eksik/yanlış girişte hata verir. Dosya adları ve içerikler commit edilmez.

Referans dosyası, GitHub'ın tek-secret 48 KB sınırına uyması için 16 kbps Opus'a dönüştürülmüştür (kayıplı sıkıştırma). Üç secret parçalanmış **referans dosyasının taşınması** içindir; anlatım sesi parça parça üretilip birleştirilmez. Bot gizli parçaları kendi geçici GitHub runner'ında tek bir 44 saniyelik ses dosyası olarak geri açar, SHA-256 bütünlüğünü kontrol eder ve yalnızca ~10 saniyelik başlangıç/orta/son referans pencereleriyle üç kısa Türkçe ses denemesi üretir. Her denemede başka pencere kullanılır. Tam kayıt model tarafından tek seferde koşullandırılmaz. Orijinal kayıt, referans pencereleri ve secret değerleri Actions artifact çıktısına eklenmez.

GitHub Actions → **KAYIP FREKANS - V6 Serkan Ses Denemesi** → Run workflow bölümünden manuel deneyin. Çıktıdaki `voice_audition_v6.json` içinde `full_44s_reference_available` değerinin `true` olduğunu doğrulayın. Üç kısa WAV dinlenip onaylanmadıkça uzun videoda kullanıma hazır olduğu varsayılmaz. Chatterbox Multilingual 0.1.7 tek çağrıda 27–32 dakika üretmeyi garanti etmez; **tek WAV dosyası elde edilmesi**, parçalar birleştirilerek üretilmiş bir sesin kesintisiz tek üretim olduğu anlamına gelmez. Şu an V6 yalnızca ses seçme denemesidir; uzun kesintisiz seslendirme ve tam video hazır değildir.

Bu araçlarda GitHub secret'larını yazma yetkisi yoktur; üç secret'ın repository ayarlarına eklenmesi GitHub hesabı sahibinin bir kerelik özel işlemidir. Anahtarlar sohbet mesajına yapıştırılmamalıdır.
