# GitHub'a yükleme

1. Bu klasörün içindeki dosyaları GitHub repository köküne yükle.
2. `media/` klasörünü oluşturup kullanım hakkı doğrulanmış sahne kliplerini ekle.
3. `examples/restoration_plan.json` içindeki `source` yollarını ve lisans kayıtlarını güncelle.
4. GitHub → Actions → `40s Shorts Bot` → `Run workflow` ile çalıştır.
5. MP4 ve `*_qc_report.json` dosyalarını workflow Artifacts bölümünden indir.

Gerçek sahne kaynakları yoksa workflow yalnızca güvenli test demosu üretir; bu demo yayınlanamaz.
